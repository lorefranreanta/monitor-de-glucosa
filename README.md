🩸 Monitor de Glucosa Inteligente
Aplicación web interactiva de salud (E-health) diseñada específicamente para adultos mayores de 55 años, priorizando la accesibilidad visual y el control de datos médicos en tiempo real.

⚙️ Características principales
• Alertas inteligentes: Mensajes dinámicos y visuales con semáforo de colores según los rangos médicos (Hipoglucemia, Normal, Hiperglucemia).
• Base de Datos Real: Persistencia de datos local utilizando SQLite para evitar pérdidas de información.
• Filtro Multiusuario: El historial clínico se adapta automáticamente al usuario que consulta, permitiendo que varios familiares lleven su control por separado.
• Diseño Accesible (Modo Oscuro): Interfaz optimizada para pantallas móviles con tipografía escalada a 24px para facilitar la lectura.
• Control de historial: Zona de peligro con doble confirmación de seguridad para reiniciar los registros.
• Tecnologías: Python, Streamlit, SQLite, HTML5, CSS3, Git.
